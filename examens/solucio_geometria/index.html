Solucio geometria

Dades inicials: Considerem el triangle que té per vèrtexs els punts:
\(A(-2, 4)\), \(B(1, 5)\) i \(C(-1, 7)\)

Exercici 1: Perímetre i angles del triangle

1.1. Representació i Perímetre

Enunciat: Calcula la longitud de cada costat (\(d(A,B)\), \(d(B,C)\) i \(d(C,A)\)), observa que és isòsceles i determina el perímetre.

Resolució:

  • Costat AB: \(d(A,B) = \sqrt{(1 - (-2))^2 + (5 - 4)^2} = \sqrt{3^2 + 1^2} = \mathbf{\sqrt{10}}\)
  • Costat BC: \(d(B,C) = \sqrt{(-1 - 1)^2 + (7 - 5)^2} = \sqrt{(-2)^2 + 2^2} = \sqrt{8} = \mathbf{2\sqrt{2}}\)
  • Costat CA: \(d(C,A) = \sqrt{(-1 - (-2))^2 + (7 - 4)^2} = \sqrt{1^2 + 3^2} = \mathbf{\sqrt{10}}\)

    Conclusió: Com que \(d(A,B) = d(C,A)\), el triangle és isòsceles.

  • Perímetre: \(P = \sqrt{10} + 2\sqrt{2} + \sqrt{10} = \mathbf{2\sqrt{10} + 2\sqrt{2} \approx 9,15 \text{ u}}\)

1.2. Estudi dels angles

Enunciat: Troba les equacions de les rectes AC (paramètrica i contínua) i AB (implícita i explícita). Calcula l'angle \(\hat{A}\) i dedueix la resta.

Resolució:

  • Recta AC: Vector \(\vec{v} = \vec{AC} = (1, 3)\). Punt \(A(-2, 4)\).

    • Paramètrica: \(\begin{cases} x = -2 + k \\ y = 4 + 3k \end{cases}\)
    • Contínua: \(\frac{x+2}{1} = \frac{y-4}{3}\)

  • Recta AB: Vector \(\vec{u} = \vec{AB} = (3, 1)\). Pendent \(m = 1/3\).

    • Explícita: \(y = \frac{1}{3}x + \frac{14}{3}\)
    • Implícita (General): \(x - 3y + 14 = 0\)

  • Angle \(\hat{A}\):

\(\(cos \hat{A} = \frac{\vec{AB} \cdot \vec{AC}}{|\vec{AB}| \cdot |\vec{AC}|} = \frac{3(1) + 1(3)}{\sqrt{10}\sqrt{10}} = \frac{6}{10} = 0,6 \implies \mathbf{\hat{A} \approx 53,13^\circ}\)\)

  • Resta d'angles: \(\hat{B} = \hat{C} = \frac{180^\circ - 53,13^\circ}{2} = \mathbf{63,43^\circ}\)

Exercici 2: Càlcul de l'àrea amb la distància punt-recta

2.1. Equació de la base

Enunciat: Comprova que la recta que passa per A i B és coincident amb \(r: 2x - 6y + 28 = 0\).

Resolució: Si simplifiquem l'equació \(r\) dividint tots els termes per 2: \(\(\frac{2x}{2} - \frac{6y}{2} + \frac{28}{2} = 0 \implies \mathbf{x - 3y + 14 = 0}\)\) Coincideix exactament amb l'equació de la recta AB calculada anteriorment.

2.2. Altura i Àrea

Enunciat: Calcula l'altura (\(h\)) com a distància de \(C\) a \(r\) i troba l'àrea.

Resolució: * Altura: \(d(C, r) = \frac{|1(-1) - 3(7) + 14|}{\sqrt{1^2 + (-3)^2}} = \frac{|-1 - 21 + 14|}{\sqrt{10}} = \frac{|-8|}{\sqrt{10}} = \mathbf{\frac{8}{\sqrt{10}}}\) * Àrea: \(S = \frac{\text{base} \cdot h}{2} = \frac{\sqrt{10} \cdot \frac{8}{\sqrt{10}}}{2} = \frac{8}{2} = \mathbf{4 \text{ u}^2}\)

Exercici 3: Càlcul de l'àrea amb la intersecció

3.1. Recta perpendicular (\(s\)): Passa per \(C(-1, 7)\) i és perpendicular a \(r\) (pendent \(-3\)): \(\(y - 7 = -3(x + 1) \implies \mathbf{3x + y - 4 = 0}\)\)

3.2. Intersecció (Punt M): Resolem el sistema entre \(r\) i \(s\): \(\(\begin{cases} x - 3y = -14 \\ 3x + y = 4 \end{cases} \implies \mathbf{M(-0.2, 4.6)} \text{ o } (-\tfrac{1}{5}, \tfrac{23}{5})\)\)

3.4. Verificació: \(d(C,M) = \sqrt{(-0,2 - (-1))^2 + (4,6 - 7)^2} = \sqrt{0,8^2 + (-2,4)^2} = \sqrt{6,4} = \mathbf{\frac{8}{\sqrt{10}}}\) L'àrea calculada amb aquesta altura torna a ser 4 u².

Exercici 4: El Paral·lelogram

4.1. Rectes paral·leles

Enunciat: Troba la paral·lela a \(AC\) per \(B\) i determina \(k\) en \(3x - ky - 66 = 0\) (paral·lela a \(AB\) per \(C\)).

Resolució: * Paral·lela a AC per B: \(m=3\), punt \(B(1, 5) \implies y-5 = 3(x-1) \implies \mathbf{3x - y + 2 = 0}\) * Càlcul de \(k\): La recta \(AB\) original és \(x - 3y + 14 = 0\). Una paral·lela ha de mantenir la proporció \((1, -3)\). En l'equació \(3x - ky - 66 = 0\), dividint per 3 queda \(x - \frac{k}{3}y - 22 = 0\). Per tant: \(\frac{k}{3} = 3 \implies \mathbf{k = 9}\).

4.2. Rectes secants

Enunciat: Justifica que les rectes són secants comparant coeficients.

Resolució: Comparem els coeficients de \(r_1: 3x - 1y + 2 = 0\) i \(r_2: 3x - 9y - 66 = 0\): \(\(\frac{A_1}{A_2} = \frac{3}{3} = 1 \quad ; \quad \frac{B_1}{B_2} = \frac{-1}{-9} = \frac{1}{9}\)\) Com que \(1 \neq \frac{1}{9}\), els coeficients no són proporcionals. Això indica que les rectes tenen pendents diferents i, per tant, són secants (es tallen en un punt \(D\)).
